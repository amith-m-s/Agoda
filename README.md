# Agoda Clone - Hotel Booking UI

A frontend recreation inspired by hotel-booking products, built with HTML5, CSS3, and vanilla JavaScript.

## Scope

- Responsive booking-oriented UI
- Destination and hotel discovery screens
- Interactive cards, modals, and transitions
- Mobile-friendly layout

This is a **frontend practice project**, not a complete hotel-booking backend. Authentication, payments, inventory, real hotel APIs, and booking persistence are intentionally out of scope.

## Stack

HTML5 · CSS3 · JavaScript · Flexbox · Grid

## Why it exists

The project demonstrates frontend implementation, responsive layout work, interaction design, and DOM/event handling.
