# 🏨 Agoda Clone – Premium Hotel Booking Platform

A modern, responsive, and scalable **Agoda-inspired hotel booking web application** built using **HTML, CSS, and JavaScript**, designed to demonstrate real-world frontend architecture and advanced UI/UX practices.

## 🚀 Features

### 🌐 User Experience
- Fully responsive design (mobile, tablet & desktop)
- Modern **glassmorphism UI**
- Smooth animations & micro-interactions
- Lazy-loaded images for performance optimization

### 🔍 Core Functionalities
- Dynamic hotel room rendering using JavaScript
- Real-time **search by city**
- Filter rooms by type (Single / Double)
- Interactive booking buttons
- Dark/Light theme toggle (UI-ready)

### 🧠 Technical Highlights
- Data-driven UI architecture
- Reusable components
- Separation of concerns (HTML / CSS / JS)
- Scalable folder structure
- Optimized DOM manipulation
